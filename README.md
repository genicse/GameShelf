# GameShelf

GameShelf 是一款面向 Windows 的桌面游戏库与游玩时长记录工具，采用 Windows 11 风格界面。它按游戏进程累计时长，也可以只在游戏窗口处于前台时计时。游戏资料保存在本机。

## 功能

- 添加游戏程序，显示程序图标，记录游玩时长和最近游玩状态。
- 按名称、游玩时长、最近游玩时间和评分查找、排序。
- 管理“想玩”“在玩”“玩过”和“未分类”状态。
- 自定义游戏名称、评分、简介、评论、相关链接和海报显示。
- 设置主题色、界面底色、背景图片和仅聚焦计时。
- 从工具启动游戏时，可一并启动指定的辅助程序。
- 处理游戏启动器与游戏本体分属不同进程的情况：可分别指定启动程序与计时进程。
- 支持通知区域驻留、本地自动保存和损坏后的备份恢复。

## 使用

从 [Releases](../../releases) 获取发行包，解压后运行 `GameShelf.exe`。Windows 会询问是否允许程序以管理员身份运行；根据需要确认 UAC 提示。使用管理员身份运行有助于识别由其他权限级别启动的游戏进程。

添加游戏时选择要启动的 `.exe`。如果启动器会再启动游戏本体，请在编辑资料时单独选择“计时进程”。开启“仅游戏窗口聚焦时计时”后，切换到其他窗口会暂停累计；否则只要游戏进程运行就会继续计时。进程检测每两秒执行一次，因此时长边界有约两秒误差。电脑休眠期间不计时。

连带启动程序只会在点击“开始游戏”时启动；已经运行的辅助程序会跳过。它们不会计入游戏时长，也不会在游戏关闭后被强制结束。

## 从源码构建

需要 64 位 Windows，以及包含 .NET Framework 4.8 兼容运行环境和 Windows Desktop/WPF 组件的系统。构建使用 Windows 自带的 C# 编译器，不需下载 NuGet 包或其他第三方依赖。

在 PowerShell 中进入仓库目录并运行：

```powershell
.\source\build.ps1
```

脚本会在仓库根目录生成 `GameShelf.exe`。运行时需要同目录下的 `GameShelf.exe.config`。

开发时可以生成不会请求管理员权限的测试构建：

```powershell
.\source\build.ps1 -TestOutput .\work\GameShelf.exe
```

运行测试构建的边界和启动参数：

```powershell
.\work\GameShelf.exe --self-test "$env:TEMP\GameShelf-tests"
```

也可用 `--data-dir "路径"` 指向独立的测试资料目录；不指定时，资料保存在程序旁的 `Data` 文件夹中。请勿把个人 `Data` 目录加入版本库。

## 数据和隐私

游戏名称、程序路径、时长、链接、笔记、设置和自定义图片只保存在本机 `Data` 文件夹。工具不上传资料、不连接游戏网站，也没有账户或云同步功能。迁移或备份资料时复制整个 `Data` 文件夹即可。

仓库 `.gitignore` 会忽略本地游戏库、自定义图片、备份和编译输出。提交代码前请检查待提交文件，确保没有意外添加个人游戏清单或本机路径。
